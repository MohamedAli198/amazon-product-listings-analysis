Amazon Product Listings Analysis

Project Overview

This project focuses on analyzing Amazon product listings to uncover insights into product pricing, customer ratings, brand performance, discounts, and customer engagement.

The project uses data analysis techniques and interactive visualizations to explore product listing data and identify meaningful business insights.

Tools & Technologies

* Excel: Data exploration and preparation.
* SQL Server: Data analysis and querying.
* Power BI: Data visualization and interactive dashboard development.

Project Objectives

* Analyze product distribution across different categories and brands.
* Explore product pricing and discount patterns.
* Evaluate customer ratings and review engagement.
* Compare brand and category performance.
* Identify relationships between pricing, ratings, and customer engagement.

Project Structure

* SQL/ – SQL queries used for data exploration and analysis.
* Power BI/ – Interactive Power BI dashboard.
* Screenshots/ – Dashboard screenshots and visualizations.
* Presentation/ – Final project presentation.
